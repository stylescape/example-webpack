    Stylescape with Webpack

    This example demonstrates using Stylescape with Webpack for bundling and optimized production builds.

    📦 Why Webpack?

    • Industry-standard bundler with extensive plugin ecosystem
    • Advanced code splitting and lazy loading
    • Hot Module Replacement (HMR) for development
    • Full control over build configuration

    Setup

    1. Install dependencies

    npm install stylescape
npm install -D webpack webpack-cli webpack-dev-server
npm install -D sass sass-loader css-loader style-loader
npm install -D html-webpack-plugin postcss-loader autoprefixer

    2. Import in your Sass

    // src/scss/styles.scss
@use "stylescape";

    3. Import in your JavaScript

    // src/js/main.js
import "../scss/styles.scss";
import "stylescape";

    4. Run development server

    npm run start

    What is Webpack?

    Webpack is a powerful static module bundler for modern JavaScript applications.

    Does it support Sass?

    Yes! With sass-loader, css-loader, and style-loader, Webpack compiles and bundles Sass seamlessly.

    What about optimization?

    Webpack offers tree-shaking, code splitting, and minification for optimized production builds.
